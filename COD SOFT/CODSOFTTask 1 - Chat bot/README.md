## 📌 Project Overview

This AI Chatbot interacts with users through predefined responses and provides an engaging command-line conversation experience. The project demonstrates fundamental Python concepts while maintaining clean, modular, and beginner-friendly code.

---

## ✨ Features

- 👋 Friendly welcome screen
- 💬 Interactive conversation
- 📖 Built-in help menu
- 😊 Greets users based on their input
- ⏰ Displays current time
- 📅 Displays today's date
- 😂 Shares random jokes
- 💡 Provides motivational quotes
- 🙏 Responds to appreciation messages
- 🚪 Exits gracefully with the `bye` command
- 🧩 Clean and modular Python code
