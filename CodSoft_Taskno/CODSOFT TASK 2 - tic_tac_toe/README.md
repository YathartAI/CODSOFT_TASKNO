## 📖 Overview

This project implements an **AI-powered Tic-Tac-Toe game** where a human competes against an intelligent computer opponent.

Unlike traditional Tic-Tac-Toe games that rely on random moves, this project uses the **Minimax Algorithm**, allowing the AI to evaluate every possible game state and always choose the optimal move.

The project demonstrates practical applications of:

- Artificial Intelligence
- Game Theory
- Decision Making
- Recursion
- Problem Solving

## 🧠 AI Algorithm

The AI is implemented using the **Minimax Algorithm**.

### How it works

- Evaluates every possible move.
- Predicts future game states.
- Maximizes the AI's winning chances.
- Minimizes the player's winning chances.
- Always chooses the optimal move.

As a result, **the AI cannot be defeated when played optimally.**
