# 🎓 AI Course Recommendation System

A smart and interactive **AI Course Recommendation System** built using **Python** as part of the **CodSoft Artificial Intelligence Virtual Internship**.

This application recommends programming and technology courses based on the user's interests through a simple command-line interface.

---

## ✨ Features

- 🤖 AI-inspired recommendation system
- 📚 30+ Technology Categories
- 🎯 Personalized course recommendations
- 🔄 Continuous recommendation mode
- ⚡ Fast and interactive terminal interface
- ⏳ AI loading animation
- 📊 Session summary
- 💡 Random learning tips
- ❌ Handles invalid input gracefully
- 👨‍💻 Professional user interface
